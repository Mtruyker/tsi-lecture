# ТСИ — библиотека лекций

Сайт курса «Технические средства информатизации»: каталог, поиск, чтение и локальный прогресс.

Материалы курса: https://github.com/Mazhirin-A-A/TSI

Исходники сайта находятся в `website/`. Сборка: `cd website && npm ci && npm run build`.

Для публикации: Settings → Pages → Source → GitHub Actions.
